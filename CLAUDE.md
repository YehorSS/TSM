# TSM

- Репозиторий публичный. При изменении того, что умеет приложение, обновлять оба README —
  `README.md` (англ.) и `README.ru.md` (рус.) — одним коммитом с изменением; скриншоты — в `docs/screenshots/`.
- Коммитить и пушить в `origin main` без отдельного вопроса.
- Интерфейс — на русском; комментарии в коде — на русском.
- Перед коммитом: `npx tsc --noEmit` и `npm test`.

# TSM

- Репозиторий публичный. При изменении того, что умеет приложение, обновлять все три README —
  `README.md` (англ.), `README.ru.md` (рус.), `README.it.md` (итал.) — одним коммитом с изменением; скриншоты на каждом языке — в `docs/screenshots/` (ru-*, en-*, it-*).
- Коммитить и пушить в `origin main` без отдельного вопроса.
- Тексты интерфейса — только в `src/ui/i18n.ts`, сразу на трёх языках (ru, en, it). Комментарии в коде — на русском.
- Перед коммитом: `npx tsc --noEmit` и `npm test`.

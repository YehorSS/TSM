# TSM — поезда, автобусы и самолёты по Италии

[English](README.md) · **Русский**

Десктопное приложение (Windows и macOS), которое находит самый дешёвый способ добраться из одного
итальянского города в другой. Пишешь одну фразу — *«Я еду из Чивитанова-Марке в Рим 31 декабря,
обратно 5 января»* — а оно сразу спрашивает Trenitalia, FlixBus и Ryanair, показывает цены по дням
и ведёт на сайт перевозчика купить билет.

Сделано для людей, которые плохо разбираются в компьютерах: один экран, крупный текст, никаких настроек.

![Поиск одной фразой](docs/screenshots/search.png)

## Что умеет

- **Поиск одной фразой.** Каждое выделенное слово — кнопка: откуда, куда, когда, обратно, транспорт.
- **Любой город Италии.** Города ищутся прямо в справочниках Trenitalia и FlixBus, поэтому находятся
  и маленькие. Можно писать по-русски: *«Чивитанова»* найдёт *Civitanova Marche*.
- **Поезд, автобус, самолёт или всё сразу.** Trenitalia (Frecciarossa, Intercity, региональные),
  FlixBus / FlixTrain, Ryanair. Ближайшие аэропорты подбираются сами по расстоянию.
- **Цены по дням.** Линия цен на неделю вокруг выбранной даты, самый дешёвый день подсвечен.
- **Период — «найди, где дешевле».** Выбираешь *с … по …* (до 31 дня) для дороги туда и обратно —
  приложение проверяет каждый день и само выбирает самый дешёвый.
- **Туда и обратно.** Два списка, самые дешёвые выбраны сразу, а плашка «Итого» говорит, за что
  именно каждая сумма: день, время, транспорт, перевозчик.
- **Метки вместо сортировки.** «Самый дешёвый», «Самый быстрый», «Лучший по цене и времени».
- **Журнал поездки.** Пересадки, ожидание, станции — простыми словами.
- **Покупка.**
  - Ryanair и FlixBus открываются сразу на выдаче нужного маршрута и дня.
  - У Trenitalia таких ссылок нет, поэтому приложение открывает Trenitalia в своём окне, где уже
    загружен список поездов на нужный маршрут и время, — остаётся выбрать поезд и нажать *Continue*.
- **Распроданные поезда скрыты** (Trenitalia отдаёт их с ценой).

## Скачать

Свежая версия — в [Releases](../../releases). Для каждой системы — один файл:

| Система | Файл |
|---|---|
| Windows 10/11 — установщик | `TSM_x.y.z_x64-setup.exe` |
| Windows 10/11 — без установки | `TSM-portable.exe` |
| macOS (Apple Silicon и Intel) | `TSM_x.y.z_universal.dmg` |

У приложения нет цифровой подписи:
- **Windows** один раз покажет «Система Windows защитила ваш компьютер» → *Подробнее* → *Выполнить в любом случае*.
- **macOS** скажет, что не может проверить приложение → правый клик по нему → *Открыть* → *Открыть*.

Переносному `.exe` нужен Microsoft Edge WebView2 — он уже есть в Windows 10/11.

## Как это работает

Своего сервера нет. Приложение обращается напрямую к тем же внутренним API, что и сайты перевозчиков:

| Перевозчик | Адрес |
|---|---|
| Trenitalia | `POST lefrecce.it/Channels.Website.BFF.WEB/website/ticket/solutions` |
| FlixBus | `GET global.api.flixbus.com/search/service/v4/search` |
| Ryanair | `GET ryanair.com/api/farfnd/v4/oneWayFares/{откуда}/{куда}/cheapestPerDay` |

Эти API **неофициальные и недокументированные** и могут измениться в любой момент. Если что-то
перестало находиться — `npm run live` покажет, какой перевозчик сломался. Italo не поддерживается:
открытого способа получить его цены нет.

Ответы кешируются на 2 часа. Дни периода запрашиваются по одному, чтобы не засыпать перевозчиков запросами.

## Сборка из исходников

Нужны Node.js 20+, Rust (stable), а для Windows — Visual Studio Build Tools с C++.
См. [требования Tauri](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run dev          # в браузере на http://localhost:1420 (CORS обходится прокси Vite)
npm run tauri dev    # в окне приложения
npm run tauri build  # установщики в src-tauri/target/release/bundle/
npm test             # тесты на сохранённых реальных ответах API
npm run live         # живая проверка всех перевозчиков
```

Сборка под macOS идёт в GitHub Actions: запушь тег `v*` (или запусти workflow *build* вручную),
и файлы появятся в черновике релиза.

## Структура

```
src/
  core/        поиск, метки, календарь цен, кеш, справочник городов, поиск любого города, покупка
  providers/   trenitalia.ts, flixbus.ts, ryanair.ts — по файлу на перевозчика, один интерфейс
  ui/          экраны: фраза поиска, результаты, туда-обратно, календарь, журнал поездки
src-tauri/     оболочка приложения (Rust); trenitalia.js — скрипт окна Trenitalia
tests/         Vitest; фикстуры — реальные ответы перевозчиков
```

## Оговорка

Это личный проект, не связанный с Trenitalia, FlixBus или Ryanair. Он только читает публичные
результаты поиска и отправляет покупать билеты на сайты самих перевозчиков. Цены — те, что
перевозчики вернули в момент поиска; окончательная цена — всегда на сайте перевозчика.

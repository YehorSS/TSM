# TSM — поиск поездок по Италии (дизайн)

Дата: 2026-10-24

## Цель
Десктопное приложение (Windows + macOS) для себя, друзей и семьи. Пользователь указывает
«откуда → куда» и дату, приложение само находит поезда, автобусы и самолёты, показывает,
где купить и в какие дни дешевле. Главный критерий — понятность для человека, который
не разбирается в компьютерах.

## Рамки первой версии
- Только Италия, только билет в одну сторону, 1 взрослый.
- Каждый вариант — один перевозчик (смешанные маршруты «автобус + самолёт» — не делаем).
- Фильтр транспорта: Всё / Поезд / Автобус / Самолёт.
- Покупка — кнопка «Купить» открывает сайт перевозчика в браузере.
- Своего сервера нет: запросы идут прямо из приложения.
- Язык интерфейса — русский.

## Источники данных (проверены 2026-10-24)
Все неофициальные — внутренние API сайтов. Могут сломаться без предупреждения.

| Перевозчик | Запрос | Даёт |
|---|---|---|
| Trenitalia | `POST lefrecce.it/Channels.Website.BFF.WEB/website/ticket/solutions` (id станций из `.../locations/search`; есть id «весь город») | поезда, пересадки, цена |
| FlixBus | `GET global.api.flixbus.com/search/service/v4/search` (id городов из `/search/autocomplete/cities`) | рейсы, цена, места |
| Ryanair | `GET ryanair.com/api/farfnd/v4/oneWayFares/{A}/{B}/cheapestPerDay?outboundMonthOfDate=` | самый дешёвый рейс на каждый день месяца |
| Italo | — | вторая очередь (открытого API с ценами не найдено) |

## Архитектура
Tauri 2 + React + Vite + TypeScript.

```
src/
  providers/        по файлу на перевозчика: trenitalia.ts, flixbus.ts, ryanair.ts
  core/
    types.ts        Trip, City, Mode
    cities.ts       справочник: город → id Trenitalia, id FlixBus, аэропорты (IATA)
    search.ts       опрашивает модули параллельно, сводит результаты, ставит метки
    cache.ts        кеш ответов (localStorage, 2 часа)
    http.ts         fetch: в Tauri — plugin-http (без CORS), в браузере — dev-прокси Vite
  ui/
    SearchScreen    поиск-фраза
    ResultsScreen   фраза-ответ, горизонт цен по дням, карточки
    TripDetails     бортовой журнал поездки
    styles.css      палитра сайта Stellar Horizons
src-tauri/          оболочка, сборка .msi/.exe и .dmg
```

Контракт модуля:
```ts
interface Provider {
  mode: 'train' | 'bus' | 'plane'
  name: string
  search(from: City, to: City, date: string /* YYYY-MM-DD */): Promise<Trip[]>
}
interface Trip {
  provider: string; mode: Mode
  depart: string; arrive: string        // ISO со смещением
  from: string; to: string              // названия станций/аэропортов
  price: number | null                  // EUR
  changes: number
  vehicles: string[]                    // «Frecciarossa 9611», «FlixBus»
  buyUrl: string
}
```

Поток: `search(from, to, date, modes)` → `Promise.allSettled` по нужным модулям →
успешные результаты сводятся и сортируются по времени отправления; упавшие модули
дают список «кто не ответил». Метки: самый дешёвый (min price), самый быстрый
(min duration), лучший (min `price + 15 € × часы в пути`).

Календарь цен: 7 дней начиная с выбранного; на каждый день — минимальная цена
среди модулей (Ryanair отдаёт месяц одним запросом, остальные — запрос на день).
Дни считаются в фоне после основного результата, кеш убирает повторы.

## Интерфейс
Стиль — сайт Stellar Horizons (`D:\VsStudio\Site\src\styles.css`): чёрный фон,
белый акцент, шрифт Onest, моноширинные подписи, печатающиеся строки.

1. **Поиск — фраза:** «Я еду из [Милана] в [Рим] [завтра], [любым транспортом]» +
   большая кнопка «Найти». Каждое слово в рамке — кнопка/поле с подсказками городов.
   Ниже — последние поиски.
2. **Результаты:** крупная фраза-ответ («Дешевле всего — в среду, автобусом, 19 €»),
   горизонт цен на 7 дней (клик по дню — новый поиск), карточки с метками и кнопкой
   «Купить». Индикатор «ПРИЁМ · 2 из 3» — какие перевозчики ответили.
3. **Подробности:** журнал поездки `T+0:00 · станция` по участкам.

Доступность: основной текст не тусклее `#c4c1cb`, шрифт от 18px, кнопки от 48px
высотой, всё доступно с клавиатуры, фокус виден.

## Ошибки
- Модуль упал или ответил ошибкой → строка «Trenitalia сейчас не отвечает —
  показываю остальных». Технических текстов пользователь не видит.
- Ничего не нашлось → «На этот день вариантов нет» + подсказка выбрать соседний день
  на горизонте.
- Нет интернета → «Нет связи с интернетом» и кнопка «Попробовать снова».

## Тесты
- Vitest: каждый модуль разбирает сохранённый реальный ответ (фикстуры в `tests/fixtures`).
- Тест сводки: метки и обработка упавшего модуля.
- Ручной скрипт `npm run live` — живые запросы ко всем перевозчикам, когда что-то сломалось.
- UI проверяется скриншотами через Playwright в браузере (dev-прокси Vite).

## Сборка
- Windows: `npm run tauri build` → `.msi` / `.exe` (без подписи — один раз предупреждение SmartScreen).
- macOS: собирается на Mac или в GitHub Actions → `.dmg` (без подписи — открыть через правый клик).

# TSM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Десктоп-приложение поиска поездов/автобусов/самолётов по Италии с календарём цен.

**Architecture:** React-интерфейс в Tauri 2. Модули перевозчиков на TypeScript ходят в
неофициальные API через `core/http.ts` (Tauri plugin-http в приложении, прокси Vite в браузере).
`core/search.ts` сводит результаты и ставит метки.

**Tech Stack:** Tauri 2, React 19, Vite 6, TypeScript, Vitest, Playwright (скриншоты).

**Spec:** `docs/superpowers/specs/2026-10-24-tsm-design.md`

## Global Constraints
- Язык интерфейса — русский; технические тексты ошибок пользователю не показываются.
- Палитра/шрифт — из `D:\VsStudio\Site\src\styles.css`, шрифт Onest-Variable.ttf копируется в `public/fonts`.
- Основной текст не тусклее `#c4c1cb`, шрифт ≥ 18px, кнопки ≥ 48px.
- Цены в EUR, 1 взрослый, в одну сторону.
- Кеш 2 часа (`localStorage`).

## Review Focus
- Перевозчик вернул ошибку/таймаут → остальные результаты всё равно показаны (тест в Task 3).
- Цена `null` (нет мест/не продаётся) → вариант не участвует в «самом дешёвом» (Task 3).
- Город без аэропорта / без FlixBus → модуль молча возвращает `[]`, а не падает (Task 2).
- Поиск на прошедшую дату → кнопки «Сегодня/Завтра», дата в календаре не раньше сегодня (Task 4).
- Рейс после полуночи (прибытие на следующий день) → длительность считается по ISO-времени, не по часам (Task 3).

**Files:** Create `package.json`, `vite.config.ts`, `index.html`, `src/main.tsx`, `src/core/types.ts`, `src/core/http.ts`, `src/core/cities.ts`, `tests/cities.test.ts`

- `type Mode = 'train'|'bus'|'plane'`; `Trip` и `Provider` — как в спеке; `City = { key, name, nameIn /* «Милана» */, tren: number|null, flix: string|null, airports: string[] }`.
- `fetchJson(url: string, init?: RequestInit): Promise<any>` — в Tauri `@tauri-apps/plugin-http`, иначе переписывает хосты на `/px/<host>/...` (прокси Vite).
- `CITIES: City[]`, `findCities(q: string): City[]` (поиск по началу рус./ит. названия, без учёта регистра).

- [ ] Тест: `findCities('мил')[0].key === 'milano'`, `findCities('Rom')[0].key === 'roma'`, у каждого города `tren` или `flix` задан.
- [ ] Реализация; ~20 крупных городов (id Trenitalia «весь город», id Flix из autocomplete, IATA).
- [ ] `npx vitest run` → PASS; коммит.

### Task 3: Сводка, метки, кеш, календарь

**Files:** Create `src/core/search.ts`, `src/core/cache.ts`, `tests/search.test.ts`

**Interfaces — Produces:**

- `priceDays(from, to, start: string, days = 7, modes): Promise<{ date: string; min: number|null }[]>`

- [ ] Тесты: упавший провайдер → в `failed`, остальные trips есть; `price:null` не становится cheapest; длительность через полночь корректна; trips отсортированы по `depart`.
